# Email drafting

Follow this process when drafting any email:

1. **Establish context first.** If not obvious from the conversation, ask (in
   one message) for: recipient + relationship, purpose, desired outcome, and
   tone (formal / friendly / firm). Never invent facts, prices or dates.
2. **Structure**: subject line (≤8 words, concrete) · greeting matched to the
   relationship · opening line that states why you're writing · body in short
   paragraphs (one idea each, ≤3 sentences) · a single clear call-to-action ·
   sign-off matched to tone.
3. **Tone rules**: mirror the register the user described; British English by
   default; no exclamation marks in formal mail; never "I hope this email
   finds you well"; be direct without being curt.
4. **Length**: default under 150 words. Cold outreach under 100. Only exceed
   when the user supplies substantial content that must be included.
5. **Output**: present the email in a fenced block (subject line first), then
   offer at most two targeted variations (e.g. "firmer" / "warmer") — don't
   write them unless asked.
6. If the user's ask involves anything legally sensitive (dismissal, debt,
   contractual notice), add a one-line suggestion to have it reviewed — then
   draft it anyway.
